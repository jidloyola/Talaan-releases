# TALAAN — Downloads & Releases

**Forms, records & student support for the class adviser.**

TALAAN is a desktop app for DepEd Senior High School class advisers: it produces
print-perfect official forms (SF2, SF9, SF10, class record, grade sheets, slips,
certificates), records attendance and grades, and manages student-support cases
aligned with DepEd Order No. 006, s. 2026.

This repository hosts the **official installers**. The source code is private.

---

## ⬇️ Download

**[➡️ Download the latest version](https://github.com/jidloyola/Talaan-releases/releases/latest)**

On the latest release, download **`TALAAN-Setup-<version>.exe`** and run it.

> **Windows only.** The app runs on Windows 10 / 11.

## 🛠️ Installing

1. Run the downloaded **`TALAAN-Setup-…exe`**.
2. Windows may show a blue **"Windows protected your PC"** (SmartScreen) notice
   because the installer is not yet code-signed. Click **More info → Run anyway**.
3. Follow the installer. TALAAN will be added to your Start menu (and desktop).

## 🔄 Updates

TALAAN updates itself. When a new version is released and you're online, the app
shows an **update prompt** shortly after you open it — click **Download update**,
then **Restart & install** when it finishes. You can also check anytime from
**About → Check for updates**. You do **not** need to download a new installer for
updates; the first install from this page is the only manual one.
